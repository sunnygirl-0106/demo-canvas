# 视频节点与历史版本

在 demo-canvas 目录启动 `npm run dev` 后打开：

http://127.0.0.1:5273/shot-box/index.html?v=4

本轮保留 B 的就地浮出历史盒子，移除候选、对比、定稿和“设为当前版本”。

- 初始示例：原视频 → 编辑视频节点 1 → 延长视频节点 1。
- 点击编辑或延长，立即创建一个新的完整视频节点，名称可直接修改。生成后，这个节点也可以继续编辑或延长。
- 每个节点的历史包含自己产生的结果和直接衍生节点的首个结果。后续工作不递归回写祖先：A → B → C 时，C 的结果进入 B 的历史，不进入 A。
- 节点中重新生成的结果保存在本节点，展示最新结果；已有下游的输入锁定到创建时的具体视频记录，重新生成不会替换它。
- 历史按生成、编辑、延长筛选。点击卡片打开视频、提示词和参数详情。视频仍在画布上时直接定位，否则可以作为独立节点取回；原历史保留。
- 可拖动节点名称旁的把手整理画布，点击节点名称修改名称。状态保存在本机浏览器，“重新体验”恢复示例。

只演示交互，不调用模型、不计费。视频为项目已有素材；延长样例裁为新增 5 秒，不自动拼回原视频。图中的连线和输入记录用于验证引用关系，不调用下游模型。

此入口独立于主画布。此前探索版本的本机状态保留在旧键中，不迁移到这次不同的节点模型。
