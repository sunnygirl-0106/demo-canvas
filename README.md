# demo-canvas

视频创作画布交互原型，保留文本、图片、视频节点与本地素材。本轮按《功能与交互改版指引.md》改进视频面板。

- 演示：https://sunnygirl-0106.github.io/demo-canvas/
- 已连接素材的工作流：https://sunnygirl-0106.github.io/demo-canvas/?scene=1
- 公开源码：https://github.com/sunnygirl-0106/demo-canvas

推送到 `main` 后，GitHub Actions 自动运行测试、构建并发布到 GitHub Pages。

## 启动与检查

```bash
npm install
npm run dev
npm test
npm run build
```

默认地址为 `http://localhost:5273`，端口占用时以终端输出为准。
默认展示节点样例；`?scene=1` 打开已连接素材的工作流，`?scene=empty` 打开空画布。

## 视频操作

- 视频节点上方有并列的「编辑视频」「延长视频」入口。首次操作创建下游任务节点，保留源视频；再次进入恢复同一节点的草稿。
- 文生视频、首尾帧、参考素材、编辑、延长分别保存素材角色、文字、模型和参数。切换模式不删除画布资产或连接；当前不参与的连接弱化。
- 素材不够被动切走时，草稿存回它自己的模式，不跟着带进新模式：断开源视频再接上新视频，回到编辑仍是原来的文字、作用范围与参数，只清除时间范围。被挤走的草稿也不会被记上那个不支持它的模型。
- 首尾帧固定 72×60 px；可交换、替换、移除。移除首帧不会自动提升尾帧。点击已有素材预览，点击空槽添加，通过「⋯」替换或移除。
- 素材悬浮联动画布连线，停留后显示独立浮层。图片完整大图预览，视频原生播放器支持进度和声音；Esc 关闭并恢复焦点。
- `@` 选择本次实际使用的已连接资产，展示四字母随机名称，引用绑定稳定资产 ID，不代表顺序。
- 模式入口与生成校验共用同一条素材规则，不会出现入口全部置灰却仍能提交的任务。
- 某个模式用不上的素材不在面板里占位：进不去的 Tab 悬浮说原因，进得去但会忽略素材的 Tab 悬浮说一句「此模式会忽略已连接的视频节点」，连接与缩略图都不动。
- 编辑可选「整段视频 / 选取片段」。视频元数据准备好后，编辑按整数秒选修改范围，延长按 2 秒下限选参考段；点击轨道新建选区，拖动两端调整，拖动选区平移。端点及选区主体也支持方向键。
- 选区自动生成资产与时间范围引用；更改范围不覆盖文字。播放选区到终点暂停，清除后留在片段模式。更换源资产或其媒体文件清除旧时间引用。
- 延长默认向后，向前 / 向后分别表示「新增 → 原视频」「原视频 → 新增」，提示词前缀常驻显示当前方向与新增时长。新增时长在参数浮层里设置，不以 30 秒减原片时长计算。改方向只改衔接的那一头，已选好的参考段不动。
- 视频输入时长按本次有效输入计算：延长选了参考段时，原片只有那一段算进合计，不按整条原片报超限。参考视频同样要能读出时长且在 2–30 秒内。
- 模型与参数为独立入口；模型清单与平台一致，不支持当前模式或会让选区失效的型号显示原因。参数浮层即时保存清晰度、时长、比例和声音，编辑时长随原片，Seedance 2.5 首尾帧比例随首帧，编辑与延长比例随原片；可灵与 Wan 没有声音开关。提交记录与界面显示的参数一致：不锁定比例的型号照手选值提交，没有声音开关的型号不夹带声音。选取片段的意图在换源、范围待重选期间同样保留，不响应秒数的型号保持置灰，放大范围由「改为整条」显式解除。
- 画布保留节点拖动、连线、复制粘贴、撤销重做、文件上传和外部文件拖入。

## 演示范围

视频生成按钮只创建、完成并记录演示任务。可下载 JSON 查看源视频、有效资产 ID、引用、时间范围、方向、输出含义和参数快照。不调用真实模型，不扣费，不裁切编码，不生成或冒充 AI 编辑结果。

整段编辑目标为整条视频；延长目标为新增片段。本轮不自动拼回源视频，也不承诺逐帧精准修改。

状态保存在内存，刷新或切换示例场景会重置。图片与文本仍使用原有模拟生成功能。所有默认媒体位于 `public/media`，图片模拟生成仍使用在线图片。

## 验证重点

`src/store/generator.test.ts` 覆盖草稿恢复、换源、引用清理、模型兼容、任务快照，以及断线换源、模型来回切换这类连续操作。画布撤销与真实媒体元数据测试继续保留。

主目录：`src/canvas`（画布）、`src/nodes`（节点与媒体）、`src/generator`（面板、片段选择、预览、参数与任务逻辑）、`src/store`（状态）、`src/demo`（本地样例）。
